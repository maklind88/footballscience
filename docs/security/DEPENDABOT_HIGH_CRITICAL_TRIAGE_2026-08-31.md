# Dependabot High/Critical Triage — 2026-08-31

Scope: read-only triage of all open high and critical alerts reported by GitHub on 2026-08-31. No dependency was upgraded and no alert was dismissed.

## Shared dependency and distribution evidence

All 15 alerts are direct Python runtime pins under `desktop/local-video-app/tracking-providers/sam2`, not transitive npm or Rust dependencies:

- `torch==2.5.1` in `torch-requirements.txt`;
- `hydra-core==1.3.2` and `pillow==10.4.0` in `runtime-requirements.txt`.

They are not installed by the Football Science web deployment, are not dependencies of `desktop/fs-desktop-spike`, and are not embedded in its Tauri executable or frontend release. They are installed only after the separate command `npm --prefix desktop/local-video-app run tracking:install -- --accept-license` creates a provider-only virtual environment outside the application source tree. They are therefore runtime dependencies of the optional local SAM 2 tracker, not development-only dependencies.

The provider accepts a fixed SAM 2 source commit and checkpoint. The installer verifies source archive bytes/SHA-256, the extracted runtime-tree SHA-256, checkpoint bytes/SHA-256, and the FS provider runtime SHA-256. Inference performs no network access. The tracking request can select a bounded local video range and boxes, but cannot supply a checkpoint path, checkpoint hash, Hydra config path, Python target, or arbitrary image-format input.

## Decision for this branch

None of these packages is part of the web runtime, the FS desktop integration spike, or its signed frontend release. No high/critical alert is currently triggerable by an untrusted input admitted by the bounded SAM 2 job protocol. They therefore do not block the local desktop-integration security gate.

They do block future distribution of the optional SAM 2 provider without either (a) the coordinated provider-only upgrades above and full tracking regression, or (b) a release-owner acceptance backed by the same immutable checkpoint/config enforcement. If arbitrary checkpoints, Hydra configs, still images, fonts, PDF/PSD/FITS/JPEG2000 inputs, or unverified provider source are introduced, this reachability conclusion immediately expires.
